In this project I wanted to showcase what I am currently learning on my course and test it out to see if it works.

## What I have tried to show on this project:

- How to retrieve the current date and time using Java's date/time classes.
- How to display the dates in standard formats (for example, dd-MMM-yyyy).
- How to print dates in various user-chosen formats (for example, yyyy-MM-dd).
- How to add units of time to or subtract units of time from the current date and display the resulting date.
- How to convert between time zones.
